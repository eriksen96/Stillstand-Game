# STILLSTAND

A short first‑person atmospheric horror game for Windows, made in Unreal Engine 5.

At 02:47 the lights come on in a mountain power station that has been sealed since 1991. You are the night‑shift
security guard sent to find out why. All names, places and events in the game are fictional.

## Status

In development. No release has been published yet. When one is, it will appear under **Releases** on this page.

## Playing a release

1. Download the zip from the latest release and unpack it anywhere.
2. Run `Stillstand.exe`.

**Controls:** WASD to move, mouse to look, **E** to use, **F** for the flashlight, **Shift** to sprint, **Ctrl** to
crouch, **Tab** to show the objective, **Esc** to pause. Keys can be changed in Settings, and gamepads work too.

**Needs:** Windows 10/11 (64‑bit) and a DirectX 12 graphics card. An RTX 3060 or better is recommended for High
settings.
